# Автоматическая проверка игры

Из папки проекта запустите `python tests/run.py`. Нужны Python 3 и Google Chrome либо Chromium. Если браузер установлен в нестандартную папку, задайте переменную окружения `CHROME` с полным путём к исполняемому файлу.

Проверки открывают игру в отдельных временных профилях браузера и завершаются с ненулевым кодом при ошибке. Игровые библиотеки находятся в папке vendor. На GitHub этот же набор запускается при push и pull request.

Сценарий vr.js задаёт положение рук и кнопки двух виртуальных контроллеров. Он проверяет меню в шлеме, захват удочки, выпуск лески, команды вибрации, возврат на причал и отключение контроллера. Сценарий game.js проверяет общие механики воды, снастей, рыбы, разделки и продажи. Оценивать комфорт движения, силу вибрации и частоту кадров нужно в физическом шлеме.
